# 会议室预约系统 - 项目简报

## 项目概述

**项目名称**: AI会议室预约系统  
**项目类型**: Web应用（PC浏览器）  
**架构模式**: DDD（领域驱动设计）  
**技术栈**: Spring Boot 2.7.10, Java 17, MyBatis  
**创建日期**: 2024-12-19

---

## 项目背景

传统的会议室管理方式存在以下问题：
- 会议室使用情况不透明，容易产生冲突
- 线下沟通成本高，效率低下
- 缺乏会议室使用数据统计，难以优化资源配置
- 无法提前规划会议室使用，影响会议安排

## 项目目标

开发一个会议室预约管理系统，提供统一的会议室预约管理平台，支持用户自助查询、预约、取消、签到以及查看个人预约记录，降低线下沟通成本，避免会议室使用冲突。

## 核心功能（MVP）

1. **会议室查询**: 按日期、时间段、地点、容量、设备等条件查询可用会议室
2. **会议室预约**: 创建预约，自动检测时间冲突，验证业务规则
3. **预约取消**: 取消自己创建的预约，验证取消规则
4. **签到功能**: 在规定时间窗口内签到，确认会议使用
5. **我的预定**: 查看和管理自己的所有预约记录

## 目标用户

- **主要用户**: 公司/组织内部员工
- **次要用户**: 系统管理员（后续迭代）

## 技术架构

- **后端**: Spring Boot 2.7.10, Java 17, MyBatis
- **前端**: 待定（建议Vue.js 3.x 或 React）
- **数据库**: MySQL 8.0+ 或 PostgreSQL
- **架构模式**: DDD（领域驱动设计）

## 核心领域模型

- **MeetingRoom（会议室聚合根）**: 管理会议室信息和状态
- **Reservation（预约聚合根）**: 管理预约信息和生命周期
- **TimeSlot（时间段值对象）**: 时间段信息
- **ReservationStatus（预约状态值对象）**: 预约状态枚举

## 关键业务规则

1. **时间冲突检测**: 时间段不能重叠
2. **预约时间范围**: 只能预约未来30天内（可配置）
3. **会议时长限制**: 30分钟~4小时（可配置）
4. **提前预约截止**: 会议开始前5分钟不可新预约（可配置）
5. **取消时间限制**: 会议开始前5分钟内不可取消（可配置）
6. **签到时间窗口**: 会议开始前10分钟至开始后15分钟（可配置）
