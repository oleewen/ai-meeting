## 需求
### 需求：会议签到
系统必须提供会议签到功能，允许用户在会议开始前后的时间窗口内进行签到，以确认会议按计划使用。

#### 场景：成功签到
- **当** 用户已登录
- **当** 用户是该预约的创建人或受授权签到人
- **当** 当前时间在签到时间窗口内（会议开始前N分钟到开始后M分钟，如提前10分钟至延后15分钟）
- **当** 用户点击签到按钮
- **那么** 系统将预约状态标记为"已签到"
- **那么** 系统返回签到成功响应
- **那么** 预约记录显示"已签到"状态

#### 场景：签到失败（未到签到时间）
- **当** 用户尝试在签到时间窗口之前进行签到
- **那么** 系统返回签到失败响应，提示"签到时间未到，请在会议开始前X分钟至开始后Y分钟内签到"
- **那么** 系统不修改预约状态
- **那么** 签到按钮置灰或不显示

#### 场景：签到失败（超过签到时间窗口）
- **当** 用户尝试在签到时间窗口之后进行签到（如会议开始后超过15分钟）
- **那么** 系统返回签到失败响应，提示"签到时间已过"
- **那么** 系统不修改预约状态

#### 场景：签到失败（无权限）
- **当** 用户尝试对不是自己创建的预约进行签到
- **当** 且用户不是受授权签到人
- **那么** 系统返回权限错误响应，提示"只能对自己的预约进行签到"
- **那么** 系统不修改预约状态

#### 场景：已签到状态显示
- **当** 用户已成功签到
- **当** 用户查看该预约记录
- **那么** 系统显示"已签到"状态
- **那么** 签到按钮不再显示或显示为"已签到"
