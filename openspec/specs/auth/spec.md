## 需求
### 需求：用户登录认证
系统必须提供用户登录功能，支持用户使用账号和密码进行身份认证。第一期使用简单的账号密码登录，后续可扩展对接统一身份认证系统。

#### 场景：用户成功登录
- **当** 用户提供有效的用户名和密码
- **那么** 系统验证通过并创建用户会话
- **那么** 系统返回登录成功响应，包含用户基本信息
- **那么** 用户可以在后续请求中使用会话标识进行身份验证

#### 场景：用户登录失败（密码错误）
- **当** 用户提供错误的密码
- **那么** 系统返回登录失败响应，提示"用户名或密码错误"
- **那么** 系统不创建用户会话

#### 场景：用户登录失败（用户不存在）
- **当** 用户提供不存在的用户名
- **那么** 系统返回登录失败响应，提示"用户名或密码错误"
- **那么** 系统不创建用户会话

#### 场景：用户未登录访问受保护资源
- **当** 用户未登录或会话已过期
- **当** 用户尝试访问需要认证的接口
- **那么** 系统返回未授权响应（401），提示需要登录
