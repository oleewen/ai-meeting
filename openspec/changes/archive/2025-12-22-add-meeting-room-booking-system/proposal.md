# 变更：添加会议室预约系统

## 为什么
为公司/组织提供统一的会议室预约管理平台，降低线下沟通成本，避免会议室冲突。支持用户自助查询、预约、取消、签到以及查看个人预约记录，提升会议室使用效率。

## 变更内容
- **新增功能：用户认证** - 支持用户登录（第一期使用默认账号密码，后续可扩展对接统一身份认证）
- **新增功能：会议室查询** - 支持按日期、时间段、地点、容量、设备等条件查询可用会议室
- **新增功能：会议室预约** - 支持创建预约，包含冲突检测、时间范围限制、时长限制等业务规则
- **新增功能：预约管理** - 支持查看我的预定、取消预约、签到功能
- **新增前端页面** - PC浏览器适配的Web界面（登录页、查询预约页、我的预定页）
- **新增后端API** - 提供RESTful API支持上述功能
- **新增数据模型** - 会议室、预约记录等核心领域模型

## 影响
- **受影响规范**：无（全新功能）
- **受影响代码**：
  - `ai-meeting-domain` - 新增领域模型和服务
  - `ai-meeting-application` - 新增应用服务
  - `ai-meeting-infrastructure` - 新增数据访问层
  - `ai-meeting-api` - 新增API接口定义
  - `ai-meeting-service` - 新增Web控制器
  - `ai-meeting-boot` - 可能需要配置调整
- **数据库变更**：需要创建会议室表、预约记录表等
- **前端资源**：需要创建前端页面（HTML/CSS/JS或前端框架）
