## 新增需求
### 需求：会议室查询
系统必须提供会议室查询功能，允许用户根据日期、时间段和可选过滤条件查询可用的会议室。

#### 场景：按日期和时间段查询可用会议室
- **当** 用户提供日期、开始时间和结束时间
- **那么** 系统返回在该时间段内可用的会议室列表
- **那么** 每个会议室信息包含：名称、地点/楼层、可容纳人数、支持设备、可用状态

#### 场景：按地点/楼层筛选会议室
- **当** 用户提供日期、时间段和地点/楼层筛选条件
- **那么** 系统返回符合地点/楼层条件且在该时间段可用的会议室列表

#### 场景：按容量筛选会议室
- **当** 用户提供日期、时间段和最小容量要求
- **那么** 系统返回容量大于等于要求且在该时间段可用的会议室列表

#### 场景：按设备筛选会议室
- **当** 用户提供日期、时间段和设备筛选条件（如投影仪、视频会议设备、白板等）
- **那么** 系统返回包含所需设备且在该时间段可用的会议室列表

#### 场景：查看会议室详情和当日排期
- **当** 用户点击某个会议室
- **那么** 系统返回该会议室的详细信息
- **那么** 系统返回该会议室当日的所有预约记录，以时间轴形式展示

#### 场景：查询结果为空
- **当** 用户提供的查询条件没有匹配的可用会议室
- **那么** 系统返回空列表，并提示"未找到符合条件的可用会议室"

#### 场景：查询参数验证失败
- **当** 用户提供的日期格式不正确或时间段无效（开始时间≥结束时间）
- **那么** 系统返回参数错误响应，提示具体的验证错误信息
