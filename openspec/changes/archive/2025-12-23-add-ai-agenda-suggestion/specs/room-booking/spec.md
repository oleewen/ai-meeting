## 修改需求
### 需求：会议室预约
系统必须提供会议室预约功能，允许用户创建预约记录。系统必须确保预约时间段不与已有预约冲突，并遵守时间范围限制和时长限制等业务规则。系统必须支持根据会议主题通过AI生成会议议程推荐，并允许用户将生成的议程自动填入备注字段。

#### 场景：成功创建预约
- **当** 用户已登录
- **当** 用户提供有效的会议室、日期、开始时间、结束时间、会议主题
- **当** 该时间段内会议室可用（无冲突）
- **当** 预约时间在允许的时间范围内（如未来30天内）
- **当** 会议时长在允许范围内（如30分钟~4小时）
- **那么** 系统创建预约记录
- **那么** 系统返回预约成功响应，包含预约详情
- **那么** 预约记录出现在"我的预定"列表中

#### 场景：预约失败（时间段冲突）
- **当** 用户尝试预约某个时间段
- **当** 该时间段已被其他预约占用
- **那么** 系统返回预约失败响应，提示"该时间段已被预约，请选择其他时间"
- **那么** 系统不创建预约记录

#### 场景：预约失败（超出时间范围）
- **当** 用户尝试预约超过允许时间范围的时间（如超过未来30天）
- **那么** 系统返回预约失败响应，提示"只能预约未来X天内的会议室"
- **那么** 系统不创建预约记录

#### 场景：预约失败（时长不符合要求）
- **当** 用户尝试预约的时长小于最短时长要求（如小于30分钟）
- **当** 或用户尝试预约的时长大于最长时长要求（如大于4小时）
- **那么** 系统返回预约失败响应，提示具体的时长限制要求
- **那么** 系统不创建预约记录

#### 场景：预约失败（开始时间≥结束时间）
- **当** 用户提供的开始时间大于或等于结束时间
- **那么** 系统返回参数错误响应，提示"开始时间必须早于结束时间"
- **那么** 系统不创建预约记录

#### 场景：预约失败（未到提前预约截止时间）
- **当** 用户尝试预约即将开始的会议（如距离开始时间不足5分钟）
- **那么** 系统返回预约失败响应，提示"会议开始前X分钟不可预约"
- **那么** 系统不创建预约记录

#### 场景：预约时提供可选信息
- **当** 用户创建预约时提供参会人数和备注信息
- **那么** 系统保存这些信息到预约记录中

#### 场景：使用AI生成会议议程推荐
- **当** 用户已登录
- **当** 用户输入会议主题
- **当** "AI生成议程"按钮立即显示在会议主题输入框附近
- **当** 用户点击"AI生成议程"按钮
- **当** 系统调用腾讯云混元大模型API，根据会议主题生成Markdown格式的会议议程推荐
- **当** 生成的议程包含：会议目标、主要议题（3-5个）、时间分配、预期成果
- **当** 系统验证生成内容长度在50-500字符范围内
- **那么** 系统返回生成的Markdown格式议程内容
- **那么** 前端在模态框中显示议程预览，用户可查看和编辑
- **那么** 用户确认后，议程内容自动填入备注字段

#### 场景：AI生成议程失败（服务不可用）
- **当** 用户请求生成会议议程推荐
- **当** 腾讯云混元大模型API服务不可用或调用失败
- **那么** 系统返回友好提示，告知用户"AI服务暂时不可用，请稍后重试或手动输入备注"
- **那么** 系统允许用户手动输入备注信息
- **那么** 预约创建功能不受影响，可以正常创建预约

#### 场景：AI生成议程超时
- **当** 用户请求生成会议议程推荐
- **当** AI服务调用超过设定的超时时间（3秒）
- **那么** 系统返回超时提示，建议用户"请求超时，请稍后重试或手动输入备注"
- **那么** 预约创建功能不受影响，可以正常创建预约

#### 场景：AI生成议程内容长度不符合要求
- **当** 用户请求生成会议议程推荐
- **当** AI服务返回的议程内容长度不在50-500字符范围内
- **那么** 系统返回提示，告知用户"生成的议程内容不符合要求，请手动输入备注"
- **那么** 系统允许用户手动输入备注信息
- **那么** 预约创建功能不受影响，可以正常创建预约
