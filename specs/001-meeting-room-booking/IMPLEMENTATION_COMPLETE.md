## 技术实现亮点

1. **完整的分层架构**: 严格遵循domain → application → infrastructure → service分层
2. **并发控制**: 实现乐观锁机制处理并发预约冲突
3. **幂等性保证**: 数据库唯一约束 + 业务逻辑双重保障
4. **权限控制**: 过滤器确保用户只能操作自己的预约
5. **自动状态更新**: 定时任务自动更新预约状态
6. **前后端分离**: React前端 + Spring Boot后端，通过REST API通信
7. **中文支持**: 所有代码、注释、UI文本使用中文

## 启动指南

### 启动后端
```bash
cd ai-meeting-boot
mvn spring-boot:run
```

后端服务将在 http://localhost:8082 启动

### 启动前端
```bash
cd ai-meeting-frontend
npm start
```

前端应用将在 http://localhost:3000 启动

### 访问地址
- **前端应用**: http://localhost:3000
- **Swagger文档**: http://localhost:8082/swagger-ui.html
- **H2控制台**: http://localhost:8082/h2-console
  - JDBC URL: `jdbc:h2:mem:meetingdb`
  - 用户名: `sa`
  - 密码: (空)
